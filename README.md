# FTI Survey — Telegram Mini App для опросов

Платформа для электронных опросов внутри Telegram: создание опросов без программирования, прохождение с телефона, автоматическая статистика и выгрузка в Excel. Интерфейс на двух языках: **O‘zbekcha** (основной) и **Русский**.

## Возможности

**Участник**
- Главный экран со списком активных опросов (название, описание, число вопросов, примерное время, срок, статус).
- Экран опроса с кнопкой **«▶️ Начать опрос»**, затем по одному вопросу на экран с индикатором прогресса.
- После выбора ответа (один вариант, выпадающий список, да/нет, оценка) приложение **само переходит к следующему вопросу**.
- Автосохранение каждого ответа, продолжение незавершённого опроса, проверка обязательных вопросов, защита от повторной отправки.

**Администратор** (кнопка «⚙️ Boshqaruv paneli / Панель управления» видна только сотрудникам)
- 8 разделов: Главная, Опросы, Вопросы, Ответы, Результаты, Статистика, Пользователи, Настройки.
- Создание опроса на двух языках: даты, тип (анонимный / именной / с регистрацией), один раз или повторно, статус.
- Визуальный конструктор: 9 типов вопросов, неограниченное число вариантов, «Другое» с текстом, обязательность, пояснение, изображение, мин./макс. выбор; изменить, дублировать, удалить, переместить вверх/вниз.
- Предварительный просмотр (ответы никуда не сохраняются).
- **Версии опроса**: правки опубликованного опроса копятся как черновик и публикуются кнопкой «🚀 Опубликовать изменения» как новая версия. Старые ответы остаются привязаны к той версии, на которую отвечали.
- Результаты с диаграммами, просмотр каждой анкеты, дашборд с фильтрами, выгрузка в Excel (на узбекском или русском).
- Роли: Super Admin, Admin, Analyst, User. Журнал изменений.

## Технологии

| Часть | Стек |
|---|---|
| Frontend | React 18, TypeScript, Tailwind CSS, Recharts, Telegram Mini Apps SDK (`telegram-web-app.js`) |
| Backend | Python 3.12, FastAPI, SQLAlchemy 2, Alembic (миграции), openpyxl |
| База данных | PostgreSQL 16 |
| Бот | Telegram Bot API (long polling, без вебхука) |
| Запуск | Docker Compose, Caddy (автоматический HTTPS) |

## Структура

```
backend/            FastAPI API
  app/models.py       таблицы БД (опросы, вопросы, варианты, версии, ответы, роли, журнал)
  app/auth.py         проверка Telegram initData на сервере, роли
  app/routers/        public.py (участники), admin_*.py (панель управления)
  app/services/       версии, проверка ответов, статистика, Excel
  alembic/            миграции БД
  tests/              автотесты (включая полный сценарий администратора)
frontend/           React-приложение (Mini App)
  src/pages/          Home, SurveyPage, Profile, admin/*
  src/components/     SurveyRunner (прохождение опроса), UI-компоненты, диаграммы
  src/i18n.ts         тексты интерфейса uz/ru

Dockerfile          один контейнер «интерфейс + API» (для Render)

```

## Безопасность

- Каждый запрос подписан Telegram (`initData`); подпись проверяется на сервере токеном бота. Подделать Telegram ID нельзя.
- Токен бота хранится только на сервере (переменная окружения), во frontend не попадает.
- Роли хранятся в БД и проверяются на сервере для каждого действия.
- Анонимные опросы не хранят идентификатор пользователя рядом с ответами; факт участия (для правила «один раз») хранится отдельно и не связан с ответами.
- Удаление «мягкое»: опросы, вопросы и варианты, на которые уже есть ответы, не стираются из БД.
- Журнал изменений (кто и что менял) и ежедневные резервные копии БД.

## Локальная разработка

Нужны Python 3.12+, Node 20+, PostgreSQL.

```bash
# backend
cd backend
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
export DATABASE_URL=postgresql+psycopg://user:pass@localhost:5432/fti_survey
export BOT_TOKEN=123:dev DEV_MODE=true SUPER_ADMIN_TELEGRAM_IDS=1 UPLOAD_DIR=./uploads
alembic upgrade head
uvicorn app.main:app --reload --port 8000

# frontend (в другом терминале)
cd frontend
npm install
npm run dev          # http://localhost:5173, /api проксируется на :8000
```

`DEV_MODE=true` позволяет открыть приложение в обычном браузере без Telegram: пользователь берётся из `localStorage.fti_dev_user` (по умолчанию ID `1`). **Никогда не включайте DEV_MODE на сервере.**

Тесты:

```bash
cd backend
pytest -q                                   # SQLite
TEST_DATABASE_URL=postgresql+psycopg://... pytest -q   # PostgreSQL
cd ../frontend && npm run build             # проверка типов и сборка
```

Для новых изменений схемы БД: измените `app/models.py`, затем `alembic revision --autogenerate -m "описание"`.
