# Руководство администратора FTI Survey

Всё управление делается кнопками в приложении. Программировать ничего не нужно.

## Как попасть в панель управления

1. Откройте бота в Telegram и нажмите кнопку **«📋 FTI Survey»**.
2. На главном экране нажмите **«⚙️ Boshqaruv paneli / Панель управления»**. Эту кнопку видят только сотрудники.
3. Язык меняется кнопками **UZ / RU** вверху.

Разделы панели (полоса вверху листается пальцем):

| Раздел | Что там |
|---|---|
| 🏠 Главная | Основные цифры и большая кнопка «➕ Создать новый опрос» |
| 📋 Опросы | Все опросы: изменить, вопросы, просмотр, результаты, пауза, копия, удаление |
| ❓ Вопросы | Выберите опрос, чтобы открыть конструктор вопросов |
| 📨 Ответы | Список анкет по опросу, просмотр каждой анкеты |
| 📊 Результаты | Диаграммы по каждому вопросу, кнопка «📥 Скачать Excel» |
| 📈 Статистика | Общий дашборд с фильтрами по опросу и датам |
| 👥 Администраторы | Добавление администраторов по Telegram ID, роли, права, блокировка (только Super Admin) |
| 🙋 Пользователи | Все пользователи, блокировка (только Super Admin) |
| ⚙️ Настройки | Логотип, название организации, контакт поддержки, журнал изменений |

## 1. Создать опрос

1. **Опросы** → **«➕ Создать новый опрос»**.
2. Заполните название на узбекском (UZ) и русском (RU). Описание по желанию.
3. Даты начала и окончания (можно не указывать: тогда опрос без срока).
4. **Тип опроса**:
   - *Анонимный*: ответы не связаны с человеком.
   - *Именной*: к анкете сохраняется имя из Telegram.
   - *С регистрацией*: перед началом участник вводит имя и телефон.
5. **Количество прохождений**: «Один раз» или «Повторное участие разрешено».
6. Нажмите:
   - **💾 Сохранить черновик** — сохранить и продолжить позже;
   - **📋 Добавить вопросы** — сохранить и сразу перейти к вопросам;
   - **🚀 Опубликовать** — сделать опрос видимым (нужен хотя бы один вопрос).

## 2. Добавить вопросы

1. В опросе нажмите **«❓ Вопросы»**, затем **«➕ Добавить вопрос»**.
2. Введите текст вопроса на узбекском и на русском.
3. Выберите **тип вопроса**:

| Тип | Как выглядит у участника |
|---|---|
| Один вариант ответа | Список кнопок, выбирается один (сразу переход к следующему вопросу) |
| Несколько вариантов ответа | Можно отметить несколько |
| Текстовый ответ | Поле для текста |
| Числовой ответ | Поле для числа |
| Да / Нет | Две большие кнопки (сразу переход дальше) |
| Оценка от 1 до 5 | Пять кнопок со звёздами (сразу переход дальше) |
| Оценка от 1 до 10 | Десять кнопок (сразу переход дальше) |
| Выпадающий список | Список выбора (сразу переход дальше) |
| Дата | Выбор даты |

4. Для типов с вариантами заполните **Вариант №1, №2 …** на двух языках. Кнопка **«➕ Добавить вариант ответа»** добавляет ещё одно поле (вариантов может быть сколько угодно). Возле каждого варианта: ✏️ редактировать, ⬆️⬇️ переместить, 🗑️ удалить.
5. Дополнительно:
   - **Обязательный вопрос** — без ответа нельзя завершить опрос;
   - **Вариант «Другое»** — участник может вписать свой ответ;
   - **Минимум / максимум выбрать** — для «Несколько вариантов»;
   - **Пояснение** — подсказка под вопросом;
   - **🖼️ Загрузить изображение** — картинка к вопросу (JPG, PNG, WEBP, GIF, до 5 МБ).
6. Нажмите **💾 Сохранить**.

Под каждым вопросом есть кнопки: **✏️ Изменить**, **📑 Дублировать**, **⬆️ Вверх**, **⬇️ Вниз**, **🗑️ Удалить**.

## 3. Проверить перед публикацией

Кнопка **«👁️ Предварительный просмотр»** показывает опрос так, как его увидит участник. Проверьте переводы, порядок, варианты. Ответы в режиме просмотра **никуда не сохраняются** и в статистику не попадают.

## 4. Опубликовать

Нажмите **«🚀 Опубликовать»** и подтвердите. Опрос появится у пользователей на главном экране.

## 5. Изменить уже опубликованный опрос

Пример: в опросе 10 вопросов, через неделю нужно добавить ещё 5.

1. **Опросы** → нужный опрос → **✏️ Редактировать** → **❓ Вопросы**.
2. Добавьте или измените вопросы.
3. Появится жёлтая плашка «Есть неопубликованные изменения». Пока вы её не нажали, участники видят прежнюю версию.
4. Нажмите **«🚀 Опубликовать изменения»** — создаётся новая версия (2, 3 …).

Ответы, полученные раньше, остаются привязаны к той версии, на которую отвечали: удалённый вариант или изменённый текст их не портит. В «Результатах» можно смотреть все версии вместе или каждую отдельно.

## 6. Пауза, завершение, удаление

- **⏸️ Приостановить** — опрос пропадает у пользователей, ответы сохраняются; **▶️ Возобновить** возвращает его.
- Статус «Завершён» или наступившая дата окончания закрывают опрос.
- **🗑️ Удалить** — опрос уходит в архив, полученные ответы остаются в базе.
- **📑 Дублировать** — копия опроса со всеми вопросами (как черновик).

## 7. Результаты и Excel

**Результаты** → выберите опрос:

- участники, завершённые и незавершённые анкеты, процент завершения;
- по каждому вопросу: количество и процент по вариантам (столбцы или круговая диаграмма), средняя оценка, ответы «Другое» и текстовые ответы;
- **📥 Скачать Excel**: лист «Сводка» и лист «Ответы» (одна строка на анкету). Язык файла совпадает с языком интерфейса.

Раздел **Ответы** показывает каждую анкету отдельно (для анонимных опросов без имени).

Раздел **Статистика**: всего опросов, активные, участники, завершённые анкеты, ответы за сегодня, графики по дням, по статусам и по опросам. Фильтры: опрос, период.

## 8. Администраторы и роли

| Роль | Что может |
|---|---|
| Super Admin | Всё: добавляет и удаляет администраторов, меняет роли и права, все опросы, результаты, Excel, настройки, логотип, пользователи |
| Admin | Создаёт опросы, редактирует вопросы и варианты, публикует и смотрит результаты своих и разрешённых опросов, выгружает Excel (если разрешено) |
| Analyst | Только просмотр: статистика, диаграммы и Excel по разрешённым опросам. Не меняет вопросы и не удаляет опросы |
| User | Проходит опросы, панели управления не видит |

Назначать и забирать права может только Super Admin.

### Добавить администратора

1. **Панель управления** → **«👥 Администраторы»** → **«➕ Добавить администратора»**.
2. Введите **Telegram ID** сотрудника (только цифры; сотрудник может узнать его у бота [@userinfobot](https://t.me/userinfobot)).
   - «✅ Пользователь найден» — сотрудник уже открывал приложение.
   - «⏳ С этим ID ещё никто не заходил» — права заработают, когда сотрудник впервые откроет приложение через Telegram. Telegram подтверждает, что это действительно он, поэтому чужой человек этими правами воспользоваться не может.
3. По желанию укажите **имя** (оно видно в списке, пока сотрудник не зашёл).
4. Выберите **роль** и настройте **права** (подробно — ниже, «Индивидуальные права»).
5. Нажмите **💾 Сохранить**.

### Кнопки в списке

| Кнопка | Что делает |
|---|---|
| ✏️ Редактировать | Имя и роль (например, Admin → Analyst). Новые права действуют сразу |
| ⚙️ Права доступа | Переключатели прав и доступные опросы |
| 🔒 Заблокировать доступ | Временно закрывает панель управления; права сохраняются, кнопка «🔓 Вернуть доступ» их возвращает. Проходить опросы человек может |
| 🗑️ Удалить | Забирает права администратора. Человек становится обычным пользователем, его опросы и ответы остаются |

### Индивидуальные права

Для каждого администратора Super Admin включает и выключает отдельные действия: 🟢 Разрешено / 🔴 Запрещено.

| Право | Что открывает |
|---|---|
| Создание опросов | Кнопка «➕ Новый опрос», дублирование |
| Редактирование опросов | Название, описание, длительность |
| Удаление опросов | Кнопка «🗑️ Удалить» |
| Добавление и удаление вопросов | Новые вопросы, удаление, дублирование, порядок |
| Изменение типов вопросов | Смена типа у существующего вопроса |
| Добавление и удаление вариантов | Новые и удалённые варианты ответов (переименовать можно и без этого права) |
| Настройка таймеров и сроков | Даты начала и окончания |
| Управление анонимностью | Анонимный / именной / с регистрацией |
| Условные переходы | Логика вопросов |
| Изображения и видео | Загрузка картинок к вопросам |
| Шаблоны | Работа с шаблонами опросов |
| Публикация и закрытие | Опубликовать, пауза, завершить |
| Просмотр результатов | Статистика, ответы |
| Экспорт | Excel / CSV / PDF |
| Доступ участников | Сколько раз можно проходить опрос |

**Готовые наборы:** «Полный доступ к опросам», «Создание и редактирование», «Только просмотр статистики». После ручного изменения переключателей набор показывается как «Индивидуальные настройки». **«Скопировать права»** переносит переключатели и опросы другого администратора.

**Доступные опросы:** «Все опросы» или «Только выбранные», и для каждого — уровень:

- 👁 **Просмотр** — только результаты и экспорт;
- ✏️ **Редактирование** — вопросы и настройки, но без публикации и удаления;
- ⭐ **Полное управление** — всё.

Действие разрешено, только если включено право **и** уровень опроса его допускает. Свои опросы администратор всегда видит с уровнем ⭐. Analyst может только смотреть результаты и (если включено) выгружать данные.

Изменения прав действуют сразу, без перезапуска. Все проверки выполняет сервер: если кнопку открыть в обход интерфейса, сервер всё равно откажет.

В списке видны имя, Telegram ID, роль, статус («Активен», «Ожидает первого входа», «Доступ заблокирован»), дата назначения и кто назначил, последняя активность.

Защита:

- свою роль и права изменить нельзя;
- Super Admin из настройки сервера `SUPER_ADMIN_TELEGRAM_IDS` (отмечен «🔐 Из настроек сервера») меняется только в настройках Render;
- последнего действующего Super Admin нельзя понизить, заблокировать или удалить;
- все изменения прав записываются в журнал изменений (⚙️ Настройки).

### Пользователи

Раздел **«🙋 Пользователи»** (только Super Admin) — все, кто открывал приложение: поиск по имени, @username или ID, смена роли и полная блокировка (заблокированный человек не может пользоваться приложением вообще).

## 9. Настройки

**🖼 Изменить логотип** (только Super Admin): нажмите «Загрузить новый логотип» и выберите картинку (PNG, JPG или WEBP, до 2 МБ, лучше квадратную). Логотип сразу меняется в шапке, на экране приветствия и в панели управления. Кнопка «Вернуть стандартный логотип» возвращает логотип FTI. Логотип хранится в базе данных и не пропадает при перезапуске сервера.
