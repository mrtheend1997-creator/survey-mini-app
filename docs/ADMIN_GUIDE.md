# Руководство администратора FTI Survey

Всё управление делается кнопками в приложении. Программировать ничего не нужно.

## Как попасть в панель управления

1. Откройте бота в Telegram и нажмите кнопку **«📋 FTI Survey»**.
2. На главном экране нажмите **«⚙️ Boshqaruv paneli / Панель управления»**. Эту кнопку видят только сотрудники.
3. Язык меняется кнопками **UZ / RU** вверху.

Разделы панели (полоса вверху листается пальцем):

| Раздел | Что там |
|---|---|
| 🏠 Главная | Основные цифры и большая кнопка «➕ Создать новый опрос» |
| 📋 Опросы | Все опросы: изменить, вопросы, просмотр, результаты, пауза, копия, удаление |
| ❓ Вопросы | Выберите опрос, чтобы открыть конструктор вопросов |
| 📨 Ответы | Список анкет по опросу, просмотр каждой анкеты |
| 📊 Результаты | Диаграммы по каждому вопросу, кнопка «📥 Скачать Excel» |
| 📈 Статистика | Общий дашборд с фильтрами по опросу и датам |
| 👥 Пользователи | Назначение ролей, блокировка |
| ⚙️ Настройки | Название организации, контакт поддержки, журнал изменений |

## 1. Создать опрос

1. **Опросы** → **«➕ Создать новый опрос»**.
2. Заполните название на узбекском (UZ) и русском (RU). Описание по желанию.
3. Даты начала и окончания (можно не указывать: тогда опрос без срока).
4. **Тип опроса**:
   - *Анонимный*: ответы не связаны с человеком.
   - *Именной*: к анкете сохраняется имя из Telegram.
   - *С регистрацией*: перед началом участник вводит имя и телефон.
5. **Количество прохождений**: «Один раз» или «Повторное участие разрешено».
6. Нажмите:
   - **💾 Сохранить черновик** — сохранить и продолжить позже;
   - **📋 Добавить вопросы** — сохранить и сразу перейти к вопросам;
   - **🚀 Опубликовать** — сделать опрос видимым (нужен хотя бы один вопрос).

## 2. Добавить вопросы

1. В опросе нажмите **«❓ Вопросы»**, затем **«➕ Добавить вопрос»**.
2. Введите текст вопроса на узбекском и на русском.
3. Выберите **тип вопроса**:

| Тип | Как выглядит у участника |
|---|---|
| Один вариант ответа | Список кнопок, выбирается один (сразу переход к следующему вопросу) |
| Несколько вариантов ответа | Можно отметить несколько |
| Текстовый ответ | Поле для текста |
| Числовой ответ | Поле для числа |
| Да / Нет | Две большие кнопки (сразу переход дальше) |
| Оценка от 1 до 5 | Пять кнопок со звёздами (сразу переход дальше) |
| Оценка от 1 до 10 | Десять кнопок (сразу переход дальше) |
| Выпадающий список | Список выбора (сразу переход дальше) |
| Дата | Выбор даты |

4. Для типов с вариантами заполните **Вариант №1, №2 …** на двух языках. Кнопка **«➕ Добавить вариант ответа»** добавляет ещё одно поле (вариантов может быть сколько угодно). Возле каждого варианта: ✏️ редактировать, ⬆️⬇️ переместить, 🗑️ удалить.
5. Дополнительно:
   - **Обязательный вопрос** — без ответа нельзя завершить опрос;
   - **Вариант «Другое»** — участник может вписать свой ответ;
   - **Минимум / максимум выбрать** — для «Несколько вариантов»;
   - **Пояснение** — подсказка под вопросом;
   - **🖼️ Загрузить изображение** — картинка к вопросу (JPG, PNG, WEBP, GIF, до 5 МБ).
6. Нажмите **💾 Сохранить**.

Под каждым вопросом есть кнопки: **✏️ Изменить**, **📑 Дублировать**, **⬆️ Вверх**, **⬇️ Вниз**, **🗑️ Удалить**.

## 3. Проверить перед публикацией

Кнопка **«👁️ Предварительный просмотр»** показывает опрос так, как его увидит участник. Проверьте переводы, порядок, варианты. Ответы в режиме просмотра **никуда не сохраняются** и в статистику не попадают.

## 4. Опубликовать

Нажмите **«🚀 Опубликовать»** и подтвердите. Опрос появится у пользователей на главном экране.

## 5. Изменить уже опубликованный опрос

Пример: в опросе 10 вопросов, через неделю нужно добавить ещё 5.

1. **Опросы** → нужный опрос → **✏️ Редактировать** → **❓ Вопросы**.
2. Добавьте или измените вопросы.
3. Появится жёлтая плашка «Есть неопубликованные изменения». Пока вы её не нажали, участники видят прежнюю версию.
4. Нажмите **«🚀 Опубликовать изменения»** — создаётся новая версия (2, 3 …).

Ответы, полученные раньше, остаются привязаны к той версии, на которую отвечали: удалённый вариант или изменённый текст их не портит. В «Результатах» можно смотреть все версии вместе или каждую отдельно.

## 6. Пауза, завершение, удаление

- **⏸️ Приостановить** — опрос пропадает у пользователей, ответы сохраняются; **▶️ Возобновить** возвращает его.
- Статус «Завершён» или наступившая дата окончания закрывают опрос.
- **🗑️ Удалить** — опрос уходит в архив, полученные ответы остаются в базе.
- **📑 Дублировать** — копия опроса со всеми вопросами (как черновик).

## 7. Результаты и Excel

**Результаты** → выберите опрос:

- участники, завершённые и незавершённые анкеты, процент завершения;
- по каждому вопросу: количество и процент по вариантам (столбцы или круговая диаграмма), средняя оценка, ответы «Другое» и текстовые ответы;
- **📥 Скачать Excel**: лист «Сводка» и лист «Ответы» (одна строка на анкету). Язык файла совпадает с языком интерфейса.

Раздел **Ответы** показывает каждую анкету отдельно (для анонимных опросов без имени).

Раздел **Статистика**: всего опросов, активные, участники, завершённые анкеты, ответы за сегодня, графики по дням, по статусам и по опросам. Фильтры: опрос, период.

## 8. Пользователи и роли

| Роль | Что может |
|---|---|
| Super Admin | Всё, включая назначение администраторов и настройки |
| Admin | Создаёт свои опросы и управляет ими; может назначать Аналитиков |
| Analyst | Смотрит ответы, результаты и статистику всех опросов, ничего не меняет |
| User | Проходит опросы |

**Пользователи** → найдите человека (имя, @username или Telegram ID) → выберите роль → подтвердите. Человек появляется в списке после первого входа в приложение.

Super Admin может дать другому администратору доступ к чужому опросу: в форме опроса блок «Дополнительные управляющие».
