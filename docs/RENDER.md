# Развёртывание FTI Survey на Render

Файл `render.yaml` в корне репозитория описывает всё, что нужно Render:

| Что создаётся | Назначение |
|---|---|
| `fti-survey-db` | база данных PostgreSQL 16 |
| `fti-survey` | веб-сервис: и само приложение (интерфейс), и API на одном адресе `https://fti-survey.onrender.com` (точное имя Render покажет после создания) |

Интерфейс и сервер собираются в один контейнер (`Dockerfile` в корне). Telegram-бот работает через webhook внутри этого же сервиса, отдельный «воркер» не нужен.

## Шаги

1. Создайте бота у [@BotFather](https://t.me/BotFather) и сохраните токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. В Render: **New → Blueprint** → выберите репозиторий `survey-mini-app`, ветку `main`.
4. Render попросит заполнить два значения:
   - `BOT_TOKEN` — токен бота;
   - `SUPER_ADMIN_TELEGRAM_IDS` — ваш Telegram ID.
5. Нажмите **Apply**. Сборка занимает 5–10 минут.
6. Когда сервис стал **Live**, откройте `https://<адрес>/api/health` — должно быть `{"ok":true}`.
7. Откройте бота в Telegram и отправьте `/start`. Появится кнопка «📋 So‘rovnomalar / Опросы», а в меню бота кнопка «📋 FTI Survey».

Адрес приложения и webhook бота настраиваются автоматически (Render передаёт адрес сервиса в переменной `RENDER_EXTERNAL_URL`).

## Ограничения бесплатного тарифа Render

На момент написания (проверяйте актуальные условия на render.com/pricing):

- бесплатный веб-сервис «засыпает» после ~15 минут без запросов; первое открытие после паузы занимает до минуты;
- бесплатная база PostgreSQL удаляется через 30 дней, резервных копий у неё нет;
- загруженные к вопросам картинки хранятся на диске сервиса и пропадают при каждом новом развёртывании.

Для реальной работы выберите платные тарифы (в `render.yaml` замените `plan: free` на `starter` у сервиса и на `basic-256mb` у базы, либо поменяйте тариф в панели Render). Для постоянного хранения картинок добавьте к сервису Disk и укажите путь в переменной `UPLOAD_DIR`.

## Обновления

После каждого принятого PR в ветку `main` Render сам пересобирает и перезапускает сервис. Миграции базы применяются автоматически при запуске.
